# 🏨 European Hotel Rating Prediction
 
## 📌 Project Overview
 
This project focuses on analyzing more than 515,000 hotel reviews from European hotels and building a machine learning model capable of predicting hotel ratings.
 
The project combines exploratory data analysis (EDA), feature engineering, data cleaning, and predictive modeling techniques to better understand factors that influence hotel review scores.
 
---
 
## 🎯 Project Objectives
 
- Perform exploratory data analysis (EDA)
- Clean and preprocess real-world review data
- Handle missing values and inconsistencies
- Create new informative features
- Analyze feature relationships
- Build a machine learning model for hotel rating prediction
 
---
 
## 📊 Dataset
 
The dataset contains:
 
- Hotel review scores
- Positive reviews
- Negative reviews
- Hotel information
- Reviewer metadata
- Location data
- Additional review-related attributes
 
Total dataset size:
 
**515,000+ hotel reviews**
